# Security policy

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Report privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue for a security problem.

Please include what you found, how to reproduce it, and which release or commit you tested. Reports are handled on a best-effort basis; there is no guaranteed response time.

## Scope

In scope: the scripts, compose files, templates and documentation in this repository, for example a default that exposes a secret, a file written with the wrong permissions, or instructions that leave a host open.

Out of scope: bugs in NetBird, Dex, Traefik or Postgres themselves. Report those to the upstream projects, for example [NetBird](https://github.com/netbirdio/netbird/security).
